# Student Information Management — Database Design Coursework

**Status:** Coursework project summary. **No executable schema, sample-data scripts, or ERD files are currently committed here.**

## Overview

For Cal Poly Pomona's CIS 3050 database-design coursework (Spring 2026), the recorded project involved a relational student information system with students, courses, enrollments, and grades. The academic project notes describe **Third Normal Form (3NF)**, primary/foreign keys, referential integrity, joins, subqueries, aggregation, filtering, and CRUD operations.

## Evidence and limits

The coursework is supported by Career OS project notes and the CIS 3050 course record. The original schema, queries, ERD, and run results have **not** been filed in this repository. This page is therefore a project description, **not a downloadable working database**.

Without source artifacts, this repository does **not** claim: BCNF validation, stored procedures, triggers, production deployment, performance optimization, seeded databases, or cross-database compatibility.
